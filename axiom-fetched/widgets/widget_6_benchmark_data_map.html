Which data lifts which benchmark

Once we know the benchmark we want to win, we already know a great deal about the data we need to collect, because the two are tied together through published training results. When we click a data source the map shows us everything it feeds, and when we click a benchmark the map traces back to everything that feeds it. The thicker links mark the strong effects that the literature has measured, and among them the one that tends to surprise us is that code lifts general reasoning rather than only the code scores.
