Code & math are capability fuel rather than niche data

We have two surprises to work through about what we feed a model. When we add code to pretraining it lifts general reasoning well beyond coding benchmarks alone. When a domain corpus does not exist yet, we can mine one out of Common Crawl with a cheap classifier, which is the recipe that carried a 7B model into GPT-4 territory on math. Both of these ideas transfer directly into building an Indic corpus from scratch.

The surprise: when we add code to a text-only pretraining mix the model gets better at things that have nothing to do with code. We can flip the switch to mix code in and watch it happen.

Why this matters Code teaches structure alongside long-range dependencies and step-by-step procedure, and that learning transfers into plain-language reasoning. We should read these as best-case "up to" figures at sub-3B scale that remain task-dependent. published: Aryabumi et al., "To Code or Not To Code?" (up to +8.2% NL reasoning, +4.2% world knowledge, +6.6% gen win-rate, 12× code vs text-only)
The caveat, since more is not always better When we push the code share too high it can hurt syntax / morphology and factual-knowledge tasks, so we should treat code as a powerful seasoning that works best in measured amounts. published: Petty et al., TMLR 2025
V5 sourcing note We should use permissive-license code only (e.g. The Stack v2). V4's code band was thin because it drew on StarCoder alone, which is exactly the gap the cohort should close.

🌱 STEP 1
Seed math
We start with a small set of known-good math pages such as a math Q&A site, which we hold as our positive examples.
🧮 STEP 2
Train fastText classifier
We train a cheap and fast text classifier that answers "is this page math-like?", feeding it the seed pages as positives and random web pages as negatives.
⛏️ STEP 3
Recall / mine Common Crawl
We score the whole crawl and pull in the pages the classifier flags as math, so that new math pages surface for us.
📈 STEP 4
Grow corpus → repeat
We add the freshly-found pages back as seeds so that we can retrain and mine again, and each pass recovers still more.

When we continue-pretrain a 7B model on those 120B mined math tokens it reaches 51.7% on MATH (60.9% with self-consistency), which lands in GPT-4 / Gemini-Ultra territory for a 7B. published: DeepSeekMath
Why the cohort cares There is no off-the-shelf high-quality Indic corpus available to us, and this exact recipe of seeding, training a cheap classifier, recalling from the crawl, growing and repeating is how we build a quality corpus for a language or domain where none exists. We are working through math here so that we can turn the same machinery on Telugu next.
