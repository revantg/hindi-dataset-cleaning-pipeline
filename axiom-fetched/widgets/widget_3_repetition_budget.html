When we run out of fresh data, how many times can we reuse it?

When unique high-quality tokens are scarce, we repeat the corpus across epochs so that we can reach a token budget, and Muennighoff et al. found the surprising result that the first few epochs come almost free, since up through roughly ~4 epochs a repeated token is worth nearly as much as a fresh one. Once we push beyond that point the value decays, and by around ~16 epochs the extra compute buys us almost nothing, so as we set our unique stock and our target we can watch where the run lands.
