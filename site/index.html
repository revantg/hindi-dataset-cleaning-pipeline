Extraction is a boundary decision.

web / explicit

Selectors & APIs

A source-specific rule selects a known article, feed, JSON-LD object, or body subtree.

InputDOM, JSON, CSS/XPath
KeepKnown fields and source order
FailsTemplate drift, localization, missing fields
Why use it
Best precision: use when the source contract is known. Log selector version and unmatched pages rather than silently falling back.
web / baseline

Trafilatura / Resiliparse

Fast tree-based extraction removes page furniture while retaining a main-content candidate.

InputRaw HTML and tolerant DOM
KeepHeadings, paragraphs, lists, links
FailsHard layouts, formulas, dynamic-only pages
Why use it
Cheap first pass: deterministic and fast. Preserve the raw page so uncertain output can be escalated instead of guessed.
web / heuristic

JusText density

Paragraph classes use link density, stopword density, tags, and neighboring context.

InputHTML paragraph blocks
KeepContent-like blocks and context
FailsEnglish thresholds on Hindi, code, dialogue
Why use it
Heuristic trade-off: useful when templates vary, but thresholds need Indic calibration and a review set.
web / scoring

Readability

Candidate containers are scored by text amount, content shape, and link-to-text balance.

InputDOM candidates and text nodes
KeepOne likely article subtree
FailsLists, forums, multi-column pages
Why use it
Use as a comparator: disagreement with another extractor is a review signal, not permission to choose the longest result.
web / learned

MinerU-HTML / AICC

Constrained semantic labels reconstruct the selected DOM as typed, source-aligned blocks.

InputSimplified + mapping HTML
KeepTables, formulas, code, block roles
FailsModel transfer, annotation and label errors
Why use it
Escalation route: use for layouts where heuristics lose semantics. Validate on Hindi pages; source mapping is the guardrail.
web / dynamic

Browser rendering

A real browser reveals content that exists only after JavaScript, consent, or client-side routing runs.

InputURL plus render state
KeepPost-render DOM with timing
FailsCookies, ads, nondeterministic state
Why use it
Last web resort: record URL, viewport, network state, and wait condition. Never treat a browser snapshot as reproducible by default.
pdf / native

PyMuPDF text layer

Native PDF extraction exposes spans, blocks, words, coordinates, and page order.

InputDigital PDF text objects
KeepBoxes, columns, page IDs, order
FailsBad font maps, scrambled reading order
Why use it
Probe first: native text preserves more evidence than OCR when it is trustworthy. Compare coordinates before flattening.
pdf / raster

Tesseract OCR

Local LSTM recognition turns rendered page images into text with confidence signals.

InputRendered page image
KeepWords, boxes, confidence
FailsNoise, small type, Indic glyph splits
Why use it
Fallback route: keep the image, OCR version, language model, and configuration together so a correction can be traced.
pdf / layout

PP-Structure

Layout, table, formula, and reading-order models rebuild structure around OCR text.

InputPage image and OCR tokens
KeepRegions, cells, formulas, boxes
FailsComplex scripts, dense pages, wrong order
Why use it
Structure matters: a flat transcription can contain every word and still destroy a table's meaning.
speech / segment

WebRTC VAD

Short PCM frames are classified as voiced or non-voiced before recognition.

Input10–30 ms PCM frames
KeepSpeech intervals and padding
FailsQuiet speech, noise, clipped boundaries
Why use it
Segment, do not erase: save frame settings and raw audio. Aggressive mode can remove precisely the speech you need.
speech / ASR

Conformer / Whisper

Acoustic context becomes multilingual text while timestamps keep the source interval attached.

InputAudio segments + language hint
KeepTranscript, time, confidence
FailsNames, code-mixing, dialect, overlap
Why use it
Measure: score WER/CER on Hindi-literate examples and keep raw ASR separate from punctuation or speaker post-processing.
Indic / safety

Unicode guardrails

A validation layer protects meaningful script components instead of treating invisible code points as garbage.

InputCode points and normalized text
KeepZWJ, ZWNJ, virama, nukta, matras
FailsOverbroad Cf stripping, ASCII gates
Why use it
Boundary: remove only what source comparison proves is an artifact. Valid Hinglish and code-mixed text can be in scope.
03 choose the route

One principle.
Three source worlds.

The artifact tells you which evidence exists. Use the route that can still see the structure.

Parse the tree.
Select the body.

Start with a selector or a deterministic DOM baseline. Preserve headings, lists, tables, code, formulas, and source spans. Render JavaScript pages only when the static artifact is incomplete.

  • 01Mechanics: bytes → tolerant DOM → blocks → candidate scoring → typed subtree.
  • 02Best first pass: Trafilatura or Resiliparse; compare uncertain pages with JusText or Readability.
  • 03Escalate: browser render or constrained MinerU-HTML block labelling.

Read the geometry.
Then trust the text.

A PDF may look selectable while its text layer is scrambled. Probe native blocks first; render and OCR only when geometry, font mapping, or reading order fails.

  • 01Native: PyMuPDF exposes text, blocks, words, coordinates, and sorting.
  • 02Scanned: render → layout detection → OCR → boxes/confidence → reading order.
  • 03Review: compare native/OCR output and inspect Indic matras, conjuncts, and nukta.

Find the voice.
Keep the time.

Speech extraction is inference, not transcription magic. Detect voiced frames, transcribe with a Hindi-capable model, then keep timestamps and confidence beside the text.

  • 01Segment: WebRTC VAD works on short PCM frames and proposes speech intervals.
  • 02Recognize: Conformer joins local convolution with global attention; Whisper is a multilingual fallback.
  • 03Audit: score WER/CER, chunk seams, code-mixing, names, numerals, and overlap.
04 keep the signal

Do not clean away the language.

Indic extraction needs restraint. Invisible does not mean irrelevant. Latin script does not mean noise.

  • 01Preserve ZWJ / ZWNJ when they carry Brahmic orthography.
  • 02Keep virama, nukta, matras, danda and valid combining sequences.
  • 03Retain Hinglish and Romanized Indic when the scope includes natural code-mixing.
  • 04Do not hard-gate on English punctuation, stopwords, or ASCII ratio.
